# bbv TDD Academy

Bootstrap project for extreme fast kickoff.

- Library
- Unit and spec tests

__C#__: .NET Core, xUnit, FakeItEasy, Shouldly, bbv.LambdaTale
__Java__: JUnit, Mockito, Cucumber
__TS__: vitest

## Run tests

```shell
cd csharp && dotnet test
cd java && ./gradlew test
cd ts && pnpm i && pnpm run test
```
